# Express Assignment

## Getting Started

This repository contains the starter files for the Express assignment. The main goal is to read the assignment details from `Express Assignment.pdf`, then build an Express app that fulfills the required routes and features.

### 1. Read the assignment instructions

Open `Express Assignment.pdf` and review the requirements carefully. Identify the following:

- required endpoints/routes
- expected input/output format (HTML pages, JSON, form data, etc.)
- any required middleware or features (body parsing, static files, templates, validation, etc.)
- grading criteria or submission instructions

### 2. Install dependencies

From the project root, run:

```bash
npm install
```

### 3. Start the app

Use one of these commands:

```bash
node index.js
```

If you add a `start` script to `package.json`, you can also use:

```bash
npm start
```

### 4. Verify the server

Once the app is running, open your browser and visit:

```text
http://localhost:3000
```
